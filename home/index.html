    Home

    Open CAFD Map is an open-source project that maps BMW's coding data back to readable names. OpenLauncher is its free, non-invasive launcher for modern versions of E-Sys: it brings those names into E-Sys without changing anything in your E-Sys install. The database has been brought up to date to cover most G- and F-chassis coding definitions and parameters, along with FA / VO option codes.

    Downloads:

    It also adds a few quality-of-life features, all accessible from inside E-Sys:

    • Compare NCD: two NCDs side by side, with the differences highlighted
    • Cheat Sheet: cheat sheets right next to the FDL editor
    • FA / VO and SVT auto-backup: every FA and SVT you read from the car is saved automatically
    • FA Helper (v3): edit the vehicle order with every option checked against the type key, conflicts and the CAFDs your psdzdata has, backed by 8,456 type keys that ship with OpenLauncher
    • DTC (v3): read the car's fault codes in E-Sys and clear them after coding

    Where the database falls short, names and parameters are dynamically calculated to fill in the gaps.

    Compatibility
    Tested with E-Sys 25.10 and E-Sys 3.35.3 on Windows, with Python 3.10 or newer. It should work on all Java 8 and Java 11 builds of E-Sys (check the version list), but universal compatibility hasn't been guaranteed yet.

    Who it's for

    OpenLauncher is for people who code with E-Sys and want it to show BMW's real names wherever they exist, plus an essential set of quality-of-life tools, free and unlocked.

    If you want one-click coding presets, guided fault-code help or service resets, paid suites are built for that. OpenLauncher doesn't try to be one.

    Built to stay out of the way

    • Layout-verified names: BMW's names are only applied where a function's exact byte layout matches, so they never land on bits that moved between software versions.
    • Read-only renaming: names are changed in E-Sys's tree in memory only. Nothing is patched into E-Sys, and the renaming never changes coding data or anything E-Sys sends to the car.
    • Versioned FA / SVT backups: every FA and SVT read from the car is saved, and older copies are kept rather than overwritten.
    • Open and unlocked: open source (MIT code, CC0 names). Everything runs on your PC, with no account, activation or hardware lock. Updates are optional.

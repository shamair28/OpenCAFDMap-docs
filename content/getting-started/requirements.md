weight = 1
+++

- **Windows** with **E-Sys** and its **psdzdata** (the psdzdata folder E-Sys is set up with).
- **Python 3.10 or newer** with tkinter. The python.org installer includes it, and no extra packages are needed.
  Setup can install Python for you with `winget`.

E-Sys 25.10 (Java 11) and E-Sys 3.35.3 (Java 8) are tested. Other versions are tried rather than blocked; see
[E-Sys versions](@/e-sys/versions.md).
